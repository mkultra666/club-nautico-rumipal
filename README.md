# Web institucional — Club Náutico Rumipal

Sitio estático moderno y responsive realizado con HTML, CSS y JavaScript puro.

## Abrir el proyecto

1. Abrí la carpeta `club-nautico-rumipal-web` en Visual Studio Code.
2. Instalá la extensión **Live Server** si todavía no la tenés.
3. Hacé clic derecho sobre `index.html`.
4. Elegí **Open with Live Server**.

También podés abrir `index.html` directamente en el navegador.

## Archivos principales

- `index.html`: estructura y textos.
- `styles.css`: diseño, colores, responsive y animaciones.
- `script.js`: menú móvil, animaciones, contadores y formulario de demostración.
- `assets/`: escudo e imagen institucional.

## Antes de publicar

Buscá y reemplazá estos datos de ejemplo:

- `5490000000000`: número de WhatsApp.
- `clubnauticorumipal@gmail.com`: correo oficial.
- `@clubnauticorumipal`: usuario de Instagram.
- Enlaces `href="#"` de las noticias.

El formulario actualmente muestra una confirmación local. Para recibir mensajes debe conectarse a un servicio como Formspree, Netlify Forms, EmailJS o un backend propio.

## Subir a Hostinger

Subí todo el contenido de esta carpeta dentro de `public_html`, manteniendo la carpeta `assets` y los nombres de los archivos.
